# Как подключить Gemini к проекту

Система направляет запросы студентов в нужные отделы с помощью Google Gemini API. Ключ бесплатный, банковская карта не нужна. Ключ хранится только на сервере, в файле `.env`.

## Быстрый старт (Windows)

1. Откройте https://aistudio.google.com/apikey и создайте API-ключ (кнопка Create API key). Если просит проект, создайте или импортируйте любой.
2. Установите Python 3.11 или новее (при установке отметьте Add Python to PATH).
3. Запустите `setup_gemini_windows.bat`.
4. Вставьте ключ (ввод скрыт). На вопрос о модели нажмите Enter: будет `gemini-3.1-flash-lite`.
5. Запустите `start_windows.bat` и откройте http://127.0.0.1:8000.
6. Войдите как студент: `240103030@sdu.edu.kz` / `Student123!`.
7. Отправьте запрос, например: `Не могу подключиться к Wi-Fi в общежитии`. Он должен уйти в IT, а в верхней плашке появится `Gemini · gemini-3.1-flash-lite · response verified`.

Проверка без браузера: `python scripts/check_ai.py`.

## Ручная настройка

Создайте файл `.env` рядом с `run.py` (его можно скопировать из `.env.example`):

```
AI_ROUTER=gemini
GEMINI_API_KEY=ваш_ключ_без_кавычек
GEMINI_MODEL=gemini-3.1-flash-lite
GEMINI_TIMEOUT_SECONDS=15
```

Каждая переменная должна встречаться ровно один раз. Пишите значения латинскими буквами.

## Что показывает плашка

| Плашка | Значение |
| --- | --- |
| Local ML · offline | Работает локальная модель, Gemini не используется |
| Gemini · key required | Выбран Gemini, но ключа нет; запросы уходят сотрудникам |
| Gemini · configured | Ключ найден, ответа от API ещё не было |
| Gemini · response verified | Последний запрос успешно обработан Gemini |
| Gemini · staff review fallback | API не ответил нормально; запрос ушёл сотруднику на ручную проверку |

Система не ломается, если Gemini недоступен: запрос сохраняется и попадает в очередь сотрудников.

## Если что-то не работает

Откройте запрос в очереди сотрудника (`helpdesk@sdu.edu.kz` / `Support123!`): в данных классификации указан `provider_error`.

- `missing_api_key`: ключ не найден. Проверьте имя переменной `GEMINI_API_KEY` в `.env`.
- `authentication`: ключ неверный или отозван. Создайте новый.
- `rate_limit`: исчерпан бесплатный лимит. Подождите или смените `GEMINI_MODEL` на другую Flash-модель из AI Studio.
- `configuration`: чаще всего неверное имя модели (в статистике AI Studio будет ошибка 404). Откройте aistudio.google.com, выберите модель и скопируйте её код (например, `gemini-3.1-flash-lite`). Модели с пометкой Paid на бесплатном ключе не работают.
- `timeout` или `network`: нет интернета или он медленный. Попробуйте увеличить `GEMINI_TIMEOUT_SECONDS` (до 30).
- `invalid_response`, `refusal`, `incomplete`: модель вернула непригодный ответ; такие запросы безопасно уходят на ручную проверку.

Ошибка `AI_ROUTER must be auto, local, or gemini (got ...)` означает, что в `.env` или в переменных Windows задано другое значение. В скобках видно, что именно прочитано.

## Безопасность и приватность

- Не загружайте `.env` на GitHub и не отправляйте ключ в чат.
- На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов. Используйте только вымышленные данные и не пишите в запросах пароли и номера карт.
- Лимиты бесплатного тарифа меняются; актуальные смотрите в Google AI Studio.

Документация: https://ai.google.dev/gemini-api/docs/quickstart
